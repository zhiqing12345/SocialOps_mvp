# SocialOps 高保真交互原型

根据《ToB 社会化运营产品需求文档 - v2》及用户提供的妙键、易撰、SocialEcho 截图制作。采用白底、蓝色主操作、固定侧栏、页签、筛选面板和卡片列表。

## 页面与可演示交互

- 工作台：白底“社会化运营总览”，按月度进度、平台统计 / 日历 / 今日待办、内容状态排列。支持按月设置各平台发布目标、查看发布日历、添加与完成待办，并保留写稿及草稿入口。目标和待办保存在原有浏览器本地数据中，旧版本数据可继续使用。
- 导航：工作台、业务进度（数据看板 / 发布记录）、竞品调研、内容创作中心、知识库（品牌知识库 / 行业优秀案例）。二级导航默认收起，点击父级展开，二级导航缩进 18px，图标、字号和行高与一级导航一致；行业优秀案例目前为独立空状态页面。品牌名称统一为“卓驭”，已有本地数据中的旧名称同步替换。
- 竞品调研：竞品洞察（平台 / 内容类型 / 关键词筛选、阅读排序、内容详情、参考创作、账号新增、CSV 导出）与热点追踪（抖音 / 微博示例热点、平台 / 分类 / 时间 / 关键词筛选、热度排序、热点详情、参考创作、CSV 导出）。
- 内容创作中心：海报创作 / 视频混剪 / 文案生成三个页签，点击文字变色且下方显示短横线。海报与视频可整理创作需求，制作服务待接入；文案生成支持约 500 字的自动驾驶示例稿、草稿保存和平台预览。执行合规检查后，编辑区直接显示四色标注，右侧品牌依据同步展示四级判断、知识来源与建议替换。
- 品牌知识库：基础信息、口径及素材检索、新增与编辑、来源标注。
- 发布记录：顶部采用圆形平台筛选、最近 7 / 30 天及全部时间选择、日期提示、导出数据和补充发布数据操作；日期范围截至当天，已发布项目按发布时间筛选，未发布项目按截止日期筛选。下方项目台账支持客户/品牌、多平台、内容类型、状态、截止日期；支持新建、编辑、行内状态调整、删除确认、平台及状态筛选、搜索、分页、CSV 导出。保留文案关联、发布链接和数据录入。仅已发布项目进入运营统计，多平台项目按首选平台统计一次；旧记录默认视为已发布，旧发布日期作为默认截止日期。
- 热点分类：行业政策解读、竞品技术宣传点、AI大事件、出行传统节点，保留“全部分类”。内容为分类对应的示例选题，未接入实时资讯。
- 数据看板：根据发布记录计算汇总指标、7 / 30 天周期、平台筛选、阅读图表、数据缺口与明细。

## 范围与演示边界

主体按文档第六章“极速 MVP”收敛，保留一个轻量首页作为原型入口，不扩展自动发布、视频生成、多租户、计费和自动周报。

品牌、账号、竞品内容与平台热点均为虚构示例。AI 与合规检查使用本地规则和模板，不调用真实模型、法规服务或 RAG 服务；检查结果用于演示品牌口径比对，最终内容仍需品牌负责人确认。新增监测账号标为“待接入”，不会实际抓取；热点追踪为本地示例，未接入抖音、微博实时热榜。平台预览仅表示内容排版，不承诺像素级还原各平台。

持久化仅使用当前浏览器 localStorage（键 socialops-prototype-v1），不提供服务端数据库、跨设备同步、身份认证或真实业务审核。原型访问权限由 Sites 托管平台控制。初始统计快照为 2026-09-09；缺失指标保留 null，汇总只包含已录入数值。图表按内容发布日期汇总累计阅读，不等于每天新增阅读。

附带可选 WebMCP 工具 start_socialops_draft，仅预填创作主题并打开工作台；无可用 WebMCP 验证上下文，未进行运行时验证。

## 本地运行

```powershell
npm install
npm run dev
```

构建：`npm run build`。类型检查：`npx tsc --noEmit`。原型未连接任何真实社媒账户，全部操作均为演示流程。
