# SocialOps 高保真交互原型

根据《ToB 社会化运营产品需求文档 - v2》及用户提供的妙键、易撰、SocialEcho 截图制作。采用白底、蓝色主操作、固定侧栏、页签、筛选面板和卡片列表。

## 页面与可演示交互

- 工作台：创作需求入口、竞品动态平台筛选、待办与工作提醒。
- 竞品追踪：平台 / 内容类型 / 关键词筛选、阅读排序、内容详情、参考创作、账号新增、CSV 导出。
- AI 文案工作台：公众号 / 微博 / 小红书 / 抖音四种模板、编辑与复制、草稿保存、文案定稿、品牌依据详情、平台预览。
- 品牌知识库：基础信息、口径及素材检索、新增与编辑、来源标注。
- 发布记录：关联已定稿文案、登记已发布链接、日期与非负整数校验、补充数据、过滤和 CSV 导出。
- 数据看板：根据发布记录计算汇总指标、7 / 30 天周期、平台筛选、阅读图表、数据缺口与明细。

## 范围与演示边界

主体按文档第六章“极速 MVP”收敛，保留一个轻量首页作为原型入口，不扩展自动发布、热榜雷达、视频生成、多租户、计费和自动周报。

品牌、账号、竞品内容均为虚构示例。AI 使用本地模板，不调用真实模型或 RAG 服务；新增监测账号标为“待接入”，不会实际抓取。平台预览仅表示内容排版，不承诺像素级还原各平台。

持久化仅使用当前浏览器 localStorage（键 socialops-prototype-v1），不提供服务端数据库、跨设备同步、身份认证或真实业务审核。原型访问权限由 Sites 托管平台控制。初始统计快照为 2026-09-09；缺失指标保留 null，汇总只包含已录入数值。图表按内容发布日期汇总累计阅读，不等于每天新增阅读。

附带可选 WebMCP 工具 start_socialops_draft，仅预填创作主题并打开工作台；无可用 WebMCP 验证上下文，未进行运行时验证。

## 本地运行

```powershell
npm install
npm run dev
```

构建：`npm run build`。类型检查：`npx tsc --noEmit`。原型未连接任何真实社媒账户，全部操作均为演示流程。
